    What this model declares

    The independent demo wire format is big-endian: D1 74 marker, 16-bit sequence, 8-bit slot count, then one 2-byte symbol per slot. DATA is 01 followed by its byte; IDLE is 00 00. Frame width is 5 + 2 × slot count. Logical indices begin at zero. This teaching format is not a native wire-format specification.

    The receiver checks exact frame count, ordered sequence, framing and symbols, single-writer slot allocation, and full byte-for-byte payload reassembly. It never sorts, repairs, substitutes, or accepts a partial payload. Bit corruption can retain valid framing and still fail the payload gate. Collision creates a declared second writer for the selected output and rejects the entire run.
